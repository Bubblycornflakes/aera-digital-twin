# ASM1 release boundary
aera.asm1 implements the 13-state, eight-process BSM1 reactor at its published temperature. SI, SS, XI, XS, XBH, XBA and XP are concentrations in g COD/m³. SO uses g O₂/m³. SNO combines nitrate and nitrite as N. SNH combines ammonia and ammonium as N. SND and XND are organic nitrogen (all four in g N/m³). SALK is mol alkalinity/m³. Organic N in live biomass and decay products enters through their nitrogen content. No separate nitrite dynamics.

The rate vector contains aerobic and anoxic heterotroph growth, autotroph growth, both decay processes, ammonification, carbon hydrolysis and coupled organic nitrogen hydrolysis. MATRIX maps rates to state changes. In days, dx/dt = (Q/V)(xin−x) + MATRIX @ rates(x); only oxygen receives kLa(SOsat−SO). Kinetics use nonnegative activities during implicit steps. Initial and inlet values must be physical. Solver failure and materially negative trajectories raise errors. Public function reactor returns the SciPy solution with state and time histories. Each future formulation requires its own state order, parameters, units and benchmark fixtures.

Verification: run .venv/bin/python -m pytest tests/test_asm1.py -q. Test nitrogen accounting with the denitrified N sink, electron equivalents, oxygen/nitrate switching, zero biomass and hydraulic tracer washout. BDF integrates each stage for a day from its inlet, passing the computed terminal outlet to the next reactor. At rtol 1e-6 and 1e-9 (atol 1e-10), all 65 terminal quantities match the reference within 0.0003 native units + 0.002% of the reference. This tolerance includes the benchmark's small steady-state discrepancies: inert XI already differs by 0.0069 between the published mixed inlet and reactor 1 despite zero biological conversion. Tighter integration alone cannot eliminate that difference.

The prescribed mixed inlet includes the benchmark's upstream recycles. This verifies the reactors conditional on that inlet.
