# Delivery sequence
0. Foundation: start both services, check annual reference arithmetic and document boundaries.
1. Engine: run seeded two-state experiments from the CLI and verify balances, energy, disturbances and controller constraints.
2. Dashboard: extend experiment workspace with playback, timeline, editable presets and synchronised charts.
3. Scene: model the basin and blowers in R3F; link bubbles, instruments and equipment to a shared sample.
4. Optimisation: compare baseline, differential evolution and a distinct proposal agent using the same training budget and held-out disturbances. Classify feasibility first.
5. Appraisal: add editable capital assumptions, CRF, NPV, energy/carbon sensitivities and reports with reproducible exports.
6. Site: add selectable illustrative plant assets, camera presets and environment lighting.
7. Release: verify workflows in browsers, capture screenshots, measure frame time on target hardware and exercise clean installation.
