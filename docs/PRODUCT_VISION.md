# Product vision
Engineers can run controlled, repeatable experiments on aeration demand and inspect how much electricity each controller consumes while maintaining treatment. Students can follow the causal sequence from influent load to oxygen demand, blower response and effluent ammonia. Asset selection and 3D cutaways will use the same time-indexed series as the charts.

The annual planning case represents a 150,000 PE UK works. The basin is a research simulation with illustrative kinetics. The application must distinguish online plant measurements, simulated quantities and reference calculations. No live plant connection exists in this release.
