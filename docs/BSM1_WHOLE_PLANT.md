# Whole-plant constant-influent verification
Run `.venv/bin/python -m aera.bsm1` from the project root. Output records all terminal concentrations after a 150-day BDF integration (rtol 1e-7, atol 1e-9). The UI shows the committed output; its regression test reruns the calculation. Open **ASM1 benchmark** in the sidebar. Browser controller settings belong to the educational experiment.

Data provenance: the IWA BSM1_R2019b archive identified by SHA256 in SCIENTIFIC_REFERENCE_REGISTER.md. Raw feed from influent_files/constinfluent.ascii. Clarifier specification from Alex et al. §2.3.3, settler1dinit.m and settler1dv4.c, model type 0. Jeppsson's Results/openloop_ss.pdf provides independent outputs. tests/bsm1_plant_reference.json contains the comparison numbers only; the solver starts from a separately specified positive biomass seed.

Volumes in m³; flows in m³/day. Raw 18446; internal recycle 55338; RAS 18446; WAS 385; effluent 18061. The feed enters layer 5 of 10 (numbered from the surface); layer depth 0.4 m, area 1500 m². Suspended solids = 0.75 times the sum of particulate COD states. Seven soluble constituents advect through each layer. The benchmark distributes outlet particulate components in feed proportions, scaled by outlet TSS. Takács settling velocity uses v0=474 and cap 250 m/day, hindered and flocculent exponents 0.000576 and 0.00286 m³/g, nonsettleable fraction 0.00228 and threshold 3000 g/m³. Adjacent-layer limiting flux and countercurrent advection share interface fluxes for conservation. Waste and return withdraw the same bottom-layer composition.

Verification checks 65 reactor concentrations, 26 stream concentrations and ten layer TSS values with the previously documented benchmark tolerance. A separate nonsteady inventory test checks exact cancellation of internal settler fluxes for all eight transported quantities. This milestone verifies constant open-loop conditions; dynamic weather and controller scenarios require separate runs against their respective reference datasets.

## V2 numerical audit and rerun
Benchmark Verification initially displays the explicitly labelled stored run. **Run numerical verification** posts to /api/asm1/benchmark, independently integrates the original initial conditions and reports errors before rounding, solver evaluations and elapsed seconds. Compare AERA minus published values; relative error uses the published denominator. The regression compares all terminal states to the published fixture. Integrator outputs now include elapsed wall time, tolerances, Jacobian evaluations, LU decompositions, minimum accepted state and captured warnings. Numerical failures raise errors. Nonnegative activities in kinetics protect internal solver probes; integrated trajectories are inspected, never clipped.

The startup saw a 0.0034 mg/L inter-solver settler-layer discrepancy at default relative tolerance 1e-7. The stricter BDF/Radau startup comparison (0.05 days, rtol 1e-9 and atol 1e-11) meets 2e-6 relative tolerance. The 150-day tighter BDF run meets the original published effluent bounds. Long Radau trials at strict tolerances were stopped for runtime; no full-duration Radau result is claimed.

## Interactive process mode
The Digital twin selector offers five-reactor ASM1 playback separately from the educational PID. Mode C requires validated site data. A 150-day baseline supplies initial conditions, cached per process. The 24-hour experiment holds raw flow and temperature constant. The optional synthetic 08:00–12:00 pulse multiplies raw SNH by 1.5; integration restarts at both discontinuities. The benchmark operating point has commands [0,0,1,1,0.35] and kLa [0,0,240,240,84] /day. Changing the fifth fixed-flow controller command changes kLa and therefore the ODEs. Five-minute samples retain each tank's concentrations and settled effluent. Flow and energy indicators cover the selected reactor. All scene materials/positions are illustrative.

Equipment mapping is an engineering assumption for this mode. Intake flow at an operating point is estimated from nominal zero-DO oxygen transfer (kLa × 8 g/m³ × reactor volume) divided by 0.28 kg O₂/m³ intake air and 20% transfer efficiency. This design conversion is distinct from instantaneous biological demand and actual transfer kLa(8−SO). Ideal-gas isentropic compression from 101.325 to 156.325 kPa absolute uses gamma 1.4, isentropic efficiency 72%, motor efficiency 94%. Multiplying kW by elapsed hours gives electrical kWh. Assumed constants have no site uncertainty estimates. This maps constant commands to equipment estimates; it does not establish the characteristic curve of a particular machine or reproduce BSM1's aeration cost index. Field calibration, dynamic weather verification, variable-temperature kinetics and advanced controllers are separate gates.
